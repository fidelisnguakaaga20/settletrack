# Known Limitations

## Current MVP Limitations

- Paystack sync is currently a placeholder implementation
- Only CSV + Paystack workflow is supported
- No Flutterwave support
- No Monnify support
- No PDF export
- No team accounts
- No email notifications
- No mobile app

## Scope

This MVP focuses only on:

- Transaction import
- Reconciliation
- Mismatch detection
- Dashboard reporting
- CSV export
- Duplicate CSV uploads were discovered during pilot testing and fixed by skipping existing CSV transaction references per business.
