# SettleTrack Demo Guide

## Demo Flow

1. Register or log in.
2. Create a business profile.
3. Upload a valid CSV transaction file.
4. View imported transactions.
5. Run reconciliation.
6. Review matched and mismatched records.
7. Check dashboard summary.
8. Export transaction CSV report.

## What To Observe

- Was the CSV upload easy?
- Were mismatch results understandable?
- Did dashboard totals make sense?
- Was the exported CSV useful?
- What confused the user?
