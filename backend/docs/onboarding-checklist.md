# SettleTrack Pilot Onboarding Checklist

## Account Setup

* Register account
* Login successfully
* Create business profile
* Confirm business details are correct

## CSV Upload

* Download sample CSV format
* Populate sample transactions
* Upload CSV file
* Confirm transactions appear in dashboard

## Reconciliation

* Run reconciliation
* Review matched transactions
* Review unmatched transactions
* Review mismatch results

## Dashboard

* Verify total payments
* Verify successful payments
* Verify failed payments
* Verify mismatch count

## Export

* Export transaction report
* Verify downloaded CSV contents

## Feedback

* Was CSV upload easy?
* Was reconciliation understandable?
* Did the dashboard provide useful information?
* Would you use this for your business?
* What would you improve?
