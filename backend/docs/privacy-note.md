# SettleTrack Privacy Note

SettleTrack stores business transaction records for reconciliation purposes only.

## Data Collected

- Business information
- Transaction records
- Uploaded CSV files
- Reconciliation results

## Data Usage

- Transaction matching
- Mismatch detection
- Reporting and export

## Security

- Authentication required
- Business data isolation enforced
- Provider credentials protected
- No payment processing performed

## Important

SettleTrack does not move, hold, or process customer funds.
