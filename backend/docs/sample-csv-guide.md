# SettleTrack Sample CSV Guide

Required columns:

- transaction_reference
- amount
- status
- payment_date
- customer_identifier
- provider
- settlement_reference

Example:

```csv
transaction_reference,amount,status,payment_date,customer_identifier,provider,settlement_reference
TXN-001,5000,success,2026-05-24T22:10:00,customer@example.com,PAYSTACK,SETTLE-001
